# Callora AI

A premium Voice AI SaaS landing page built with React, TypeScript, Tailwind CSS and Framer Motion.

## Features

- AI Voice Receptionist landing page
- Interactive conversation demo
- Analytics dashboard
- Dark / Light mode
- Responsive design
- Modern SaaS UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## Local Setup

```bash
npm install
npm run dev
```
